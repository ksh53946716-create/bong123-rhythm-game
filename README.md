# Bong's Game

박자에 맞춰 펀치! 턴제 격투 리듬게임 (웹 · 설치형 앱(PWA) · Android · 데스크톱)

- 플레이: https://ksh53946716-create.github.io/bong123-rhythm-game/
- 로그인·랭킹: Firebase Authentication(구글 / 아이디+비밀번호) + Cloud Firestore
- `firestore.rules`: Firestore 보안 규칙 (Firebase 콘솔 → Firestore → 규칙에 게시)
- 음악: 퍼블릭 도메인 클래식 · 민요 편곡 + 오리지널 EDM + Kevin MacLeod 곡 (CC BY 4.0)
